# Plan 03-01: Snapshot-Aware Card Filters

## Objective

Add snapshot switching and category filtering to the card detail workflow while preserving the selected card context.

## Tasks

1. Reuse the current-month/snapshot selector pattern on the card detail page.
2. Invalidate card transaction queries when snapshot view changes.
3. Add a category filter that works together with search and the fixed selected card.
4. Make filtered empty states understandable when a snapshot or category yields no transactions.

## Verification

- The card detail page can switch between Current Month and available snapshots.
- Category filtering narrows only the selected card's transactions.
- Snapshot selection and category filtering work together without losing selected-card context.
