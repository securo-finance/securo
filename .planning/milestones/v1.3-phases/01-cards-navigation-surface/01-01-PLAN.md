# Plan 01-01: Cards Route And Listing Surface

## Objective

Add a dedicated `Cartões` navigation entry and a browsable list of imported Pluggy credit cards without introducing a new backend card model.

## Tasks

1. Add the `Cartões` route and shell navigation entry below `Transações`.
2. Create a cards listing page backed by existing connected-account API data.
3. Filter the listing to imported credit-card accounts only and present recognizable card metadata.
4. Link each card tile to the dedicated card transaction workflow for later phases.

## Verification

- The shell shows `Cartões` below `Transações`.
- `/cards` renders imported credit-card accounts only.
- Each listed card is identifiable from the metadata shown on the tile.
