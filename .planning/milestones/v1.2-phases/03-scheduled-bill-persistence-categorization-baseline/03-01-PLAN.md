# Plan 03-01: Daily Bill Persistence Baseline

## Objective

Persist current-month bill imports into Flux-owned monthly storage on a daily schedule, with category assignment coming only from saved rules.

## Tasks

1. Convert the background connection sync into a daily scheduled bill check.
2. Persist imported bill rows to the active monthly-period record instead of the provider transaction month.
3. Remove Pluggy category auto-mapping and keep only rule-driven categorization on import.

## Verification

- Daily background sync still processes active/error connections.
- Imported bill transactions are associated with the active monthly period and source account.
- New imports remain uncategorized unless a saved rule applies.
