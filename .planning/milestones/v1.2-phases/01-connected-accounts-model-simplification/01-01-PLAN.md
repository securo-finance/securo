# Plan 01-01: Connected Account Surface

## Objective

Make connected accounts the only supported account-management surface, with persistent renaming, per-account bill import toggles, and hidden manual/wallet flows.

## Tasks

1. Add account metadata needed for the new surface:
   - `custom_name`
   - `bill_import_enabled`
   - migration + schema updates
2. Refactor account service and API behavior:
   - list/read supported connected accounts only
   - reject manual account creation in supported flows
   - allow rename and bill-import toggle on connected accounts
   - treat delete as a soft removal that prevents future runtime exposure
3. Update connection sync rules so provider refreshes do not overwrite custom labels.
4. Remove wallet/manual-account bootstrap from auth/setup flows.
5. Rework the `Contas` and shell UI to remove manual-account and balance-centric behavior from the supported path.

## Verification

- `Contas` shows only connected accounts.
- A connected account rename persists after refresh.
- A connected account bill import toggle can be changed from the UI/API.
- Default wallet/manual-account creation is gone from setup/register flows.
