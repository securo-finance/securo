# Plan 02-01: Pluggy Bill-Only Retrieval

## Objective

Change the Pluggy sync path so the supported runtime imports only current-month credit-card bill transactions.

## Tasks

1. Extend the provider contract with bill retrieval support and expose Pluggy `billId` on transactions.
2. Add credit-card bill selection logic based on `dueDate` in the month after `Mês Atual`.
3. Filter sync imports to bill-linked transactions only and skip non-credit-card transaction ingestion in the supported runtime.

## Verification

- Bill imports use Pluggy's documented bills API shape.
- Only credit-card bill-linked transactions are imported during connection creation and sync.
- The selected bill set tracks the month after the active monthly period.
