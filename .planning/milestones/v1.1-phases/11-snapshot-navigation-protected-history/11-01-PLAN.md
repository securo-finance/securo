# Phase 11 Plan 01: Snapshot Navigation and Protected History

## Objective

- **What:** Add app-wide snapshot selection and protected read-only history behavior on top of the Phase 10 closure contract.
- **Why:** Closing months is only useful if users can later browse preserved history confidently without confusing it for the editable `Mês Atual`.
- **Output:** A shared snapshot context contract plus UI/guard behavior that makes closed history clearly reviewable and protected.
