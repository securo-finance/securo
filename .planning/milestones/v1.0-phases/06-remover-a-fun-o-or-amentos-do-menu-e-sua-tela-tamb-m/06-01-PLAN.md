# Phase 6 Plan 01: Retire the Standalone Budgets Screen

## Objective

- **What:** Remove the standalone Budgets page from navigation and route users into Categories instead.
- **Why:** Phase 5 already made category-owned budgeting the supported flow, so the extra Budgets screen is now redundant and should not remain in the shipped UI.
- **Output:** A frontend that no longer exposes the Budgets menu entry or page while preserving a safe path for legacy `/budgets` visits.
