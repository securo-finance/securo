# Phase 3 Plan 01: Single Category Form With Inline Budget Controls

## Objective

- **What:** Merge category and budget editing into one responsive category form and downgrade the budgets page to a read-focused surface.
- **Why:** Phase 3 needs one user-facing write flow for category budget state before reader cutover work begins.
- **Output:** Updated category page/dialog, supporting copy, and API regression coverage for category budget fields.
